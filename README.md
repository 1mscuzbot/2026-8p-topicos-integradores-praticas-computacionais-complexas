  - ED 1: Linguagens de Programação no Mercado de Trabalho
  - Uso de ChatGPT e robôs (chat.openai.com) como ferramentas
  - Palestra de Certificações
  - Automatização de processos e criação de Robôs Virtuais
  - Segurança da Informação na área de TI
  - Palestra de Gestor de RH
  - Banco de Dados, Carreira e Certificações
- Elaboração de projetos em equipes de 6 integrantes
- Questões ENADE resolvidas em aula (ex: NBR ISO/IEC 27002, firewall/IDS/antivírus)
